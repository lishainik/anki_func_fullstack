# Anki-тренажёр (консольное приложение)

Интерактивная консольная программа для изучения иностранных слов по принципу Anki: пользователь переводит карточки, добавляет новые слова и сохраняет словарь между сессиями.

## Возможности

- обычная тренировка по случайным словам;
- режим «до первой ошибки»;
- добавление новых пар «слово — перевод»;
- просмотр всего словаря;
- загрузка и сохранение словаря в файл `words.txt`.

Во всех игровых режимах и при добавлении слов для выхода используется команда `СТОП` (регистр не важен).

## Запуск

```bash
python main.py
```

Файл `words.txt` должен лежать рядом с `main.py`. Формат строк:

```text
слово, перевод
```

## Меню

1. Начать игру  
2. Добавить слова  
3. Тренировка до первой ошибки  
4. Вывод всех слов  
5. Выход (с сохранением словаря)

## Структура проекта

- `main.py` — логика приложения и точка входа
- `words.txt` — словарь пользователя
- `tests/` — автотесты
